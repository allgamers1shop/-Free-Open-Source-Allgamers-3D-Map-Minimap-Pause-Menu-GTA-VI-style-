## 🛠️ Installation Guide

1. Download `allgamers_map.zip` from the [Google Drive link](https://drive.google.com/file/d/1J7Fztw9ikLXNllo_stMGmNYDYyFHTJ88/view?usp=sharing).
2. Extract the `allgamers_map` folder into your server's `resources` directory (e.g., `resources/[scripts]/allgamers_map`).
3. Open `config.lua` to adjust your keybinds, default accent colors, and map settings to match your server framework.
4. Add the start command to your `server.cfg`:
   ```cfg
   ensure allgamers_map
